Spread laboratory

牌阵不是“多抽几张”，而是先规定句法

每一个位置都是一个问题函数。先定义位置，再翻牌；先逐位作答，再做横向综合，能显著减少看到牌后临时编故事。

牌阵设计四原则

  1. 一个位置只问一件事。
  2. 位置彼此不同，但共同服务总问题。
  3. 描述机制、资源与选择，少设“他到底怎样”的读心位。
  4. 张数只随问题复杂度增加，不随焦虑增加。

三张机制牌阵

用“驱动—阻碍—可行行动”代替模糊的“过去—现在—未来”，更适合训练因果关系与现实落点。

综合顺序：主轴 → 张力 → 重复元素 → 缺失元素 → 边界句。

Serious study path

从“背关键词”到建立自己的解读模型

经典资料提供历史语境与原始牌义，现代训练负责把它们变成可操作、可复盘、不过界的阅读方法。经典不等于唯一答案，也不应脱离问题机械套用。

阶段一｜图像与结构

  • 78张总体结构、元素×数字矩阵
  • 人物朝向、视线、距离、颜色与地景
  • 只描述可观察事实，不急着解释

阶段二｜位置化翻译

  • 同一张牌放在原因、建议、趋势的动词变化
  • 人物牌作为人、角色、态度或成熟度
  • 逆位的四种机制，而非简单反义词

阶段三｜组合语法

  • 递进、因果、冲突、修复、内外、主次
  • 元素密度与缺失、数字递进与回退
  • 牌阵位置比单张关键词优先

阶段四｜高阶建模

  • 为同一组牌保留至少两种竞争性解释
  • 写出支持证据、反证和置信度
  • 用现实反馈校准个人偏差

阶段五｜伦理与提问

  • 把“他会不会”改写为可行动、可核实的问题
  • 不替代医疗、法律、财务与安全判断
  • 不把牌用于确诊、定罪或读取他人隐私

阶段六｜刻意练习

  • 盲读 → 揭示 → 自评 → 记录错误类型
  • 同牌三语境、同题两牌阵、隔日重读
  • 建立自己的语料库，而不是扩张绝对关键词
经典参考基线：本系统以 Rider–Waite–Smith 图像体系及 A. E. Waite《The Pictorial Key to the Tarot》（1911）为历史基线，再以结构化学习方法重新组织。可查阅 原书目录与全文；牌面来自 Wikimedia Commons 公版图像集。经典文本中部分占卜断语具有时代性，本系统不会把它们当作确定事实。
Advanced methodology

进阶与高阶学习路径

进阶不是增加更多绝对关键词；高阶也不是把故事讲得更玄。层级越高，越重视证据、替代解释与复盘。

基础｜语义准确

识别牌类、核心动作、常见误区，并能将牌义翻译到问题位置。

达标问题：这张牌最少能支持什么？

进阶｜图像与组合

从画面提取可观察线索，建立递进、因果、张力、内外或修复关系；区分人物、状态和机制。

达标问题：牌与牌之间是什么语法？

高阶｜竞争性解释

同时保留至少两种解释，写出各自需要的现实证据、可能反证与置信度，并通过后续事实复盘。

达标问题：什么事实会让我修改结论？

单牌五步法
  1. 复述问题：原因、现状、建议、态度还是趋势？
  2. 识别牌类：大牌主题；小牌领域与阶段；宫廷牌角色。
  3. 写核心动作：用动词短语，不堆关键词。
  4. 翻译到语境：不新增人物、事件、时间与结局。
  5. 加边界句：明确这张牌暂时不能回答什么。

模板：这张牌首先显示【核心动作】。放在【问题位置】中，更稳妥地表示【语境解释】。它可以推测【可能性】，但不能仅凭此确定【边界】。

两张 / 三张组合

两张牌的六种关系：递进、因果、加强、冲突、内外分工、问题—修复。

关系例子主线
递进倒吊人 → 死神悬置使旧模式走到尽头
冲突愚人 ↔ 教皇自由与正式结构拉扯
内外战车 + 力量对外推进，同时对内克制
修复高塔 → 星星冲击后恢复信任与方向

三张牌先给每张一个功能：驱动—过程—表现，或主题—限制—应对。最后必须写“不能确定什么”。

Evidence boundary

三层推断边界

把牌面视为有限证据，把解读视为带不确定性的假设。结论强度不能高于证据强度。

A｜牌面明确支持

直接来自核心牌义、问题位置与组合关系。

措辞：显示、强调、处于、倾向。

月亮：当前信息不清，情绪和直觉可能影响判断。

B｜合理推测

与牌义相容，但还存在其他解释。

措辞：可能、或许、较容易、可表现为。

月亮：可能有人没有说清楚，或双方理解有偏差。

C｜越界结论

需要额外事实，却被写成确定剧情。

警报词：一定、必然、就是、百分之百。

月亮：“他一定出轨/撒谎”——牌面不足以支持。
